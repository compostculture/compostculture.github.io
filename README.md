# Compost Science Lab — Static Site

## Setup
- `index.html` — landing page (reuses World Composting CSS theme)
- `src/styles/theme.css` — copied from World Composting for visual consistency
- `assets/` — images, logos, etc.

## Workflow
1. Draft articles in `/articles/` subfolder
2. Test locally: `python3 -m http.server 8080 --directory .`
3. Push to GitHub Pages when ready
